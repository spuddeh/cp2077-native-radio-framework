# Feature List - Native Radio Framework

## Implemented

- Custom stations play through the game's own radio system, on the Radioport, world radios and the
  vehicle radio.
- Stations are declared by a JSON manifest per mod; any number of station mods coexist.
- No vanilla file is replaced and no archive ships.

## Planned

- Replace the two roster functions and the vehicle receiver rather than patching their bounds, which
  lifts the 127-station ceiling and fixes next/previous cycling past the vanilla fourteen.
- Station name and icon on the dial, through TweakXL records and the script layer.
- Build a station in game from any installed song.
